Claude Code and Codex usage limits, in your KDE Plasma panel

Agents Usage is a free widget for KDE Plasma 6. It shows how much quota you have left in Claude Code, OpenAI Codex CLI, OpenCode and Ollama Cloud, and when each limit resets.

Download the .plasmoidv@VERSION@ Source on GitHub

What it shows

AI coding agents cut you off after a set amount of use: a five-hour session, a weekly cap, sometimes a separate limit per model. The agents tell you late, usually when you are already blocked. The widget keeps those numbers next to the clock so you can plan the next long task.

Quota left
The available percentage for every window the agent reports. Claude Code has five-hour, weekly, Sonnet and Opus windows; Codex has five-hour and weekly.
Reset time
A countdown and the local day and time of the reset, on a 24-hour clock.
Colour
Green, orange when quota is low, red when it is critical. You choose both thresholds.
Refresh
Automatic, at an interval you set, or on demand from the popup.

It never estimates. If an agent does not report a number, the widget says it is unavailable.

Install

You need KDE Plasma 6, Python 3.10 or newer and kpackagetool6. There are no Python packages to install.

  1. Install the package

    Download the .plasmoid file from the latest release and run:

    kpackagetool6 --type Plasma/Applet --upgrade io.github.kde-agents-usage-@VERSION@.plasmoid

    Or install from source, and run the script again later to update:

    git clone https://github.com/serjor/kde-agents-usage.git
cd kde-agents-usage
./install.sh

  2. Add it to the panel

    Right-click the panel, choose Add Widgets… and drag Agents Usage onto it. If it is not in the list, restart Plasma:

    systemctl --user restart plasma-plasmashell.service

  3. Connect Claude Code

    Add the collector to ~/.claude/settings.json. It works offline. If you already have a status-line command, call the collector from it instead.

    {
  "statusLine": {
    "type": "command",
    "command": "python3 ~/.local/share/plasma/plasmoids/io.github.kde-agents-usage/contents/code/claude-statusline-collector"
  }
}

Codex needs no setup. The README covers the live Codex query, OpenCode and Ollama Cloud.

Privacy

Out of the box the widget reads local files and makes no network requests. There is no telemetry and no analytics.

  • It reads only quota values, reset times and the plan name. It never stores prompts, responses or code.
  • The Anthropic and Ollama sources are off until you enable them, and each talks only to its official endpoint.
  • Tokens and API keys stay in memory. The Ollama key lives in KWallet or another Secret Service provider.
  • Cache files in ~/.cache/kde-agents-usage are readable only by you.

Found a problem? Read the security policy.

Questions

How can I see my Claude Code usage limit on Linux?

Install the Agents Usage widget on KDE Plasma 6 and connect its local status-line collector in ~/.claude/settings.json. The panel then shows the remaining percentage of your Claude Code five-hour and weekly windows, plus Sonnet and Opus windows when available.

When does my Claude Code five-hour limit reset?

Agents Usage shows a live countdown and the local reset day and time (24-hour clock) for every Claude Code quota window, so you know exactly when the five-hour and weekly limits reset.

Can I check OpenAI Codex CLI rate limits from the desktop?

Yes. By default the widget reads the last rate-limit event from local Codex session files. You can also enable a live query through the installed Codex CLI to see the current five-hour and weekly limits immediately.

Does Agents Usage send my data anywhere?

No. The default configuration makes no network requests and the project has no telemetry or analytics. Optional API sources are off by default and only contact the official Anthropic or Ollama endpoints.

Does it work with OpenCode and Ollama Cloud?

Yes. OpenCode quotas come from a small local provider export file, and Ollama Cloud usage comes from the ollama.com balance API with the API key stored in KWallet or another Secret Service provider.

Is Agents Usage free?
