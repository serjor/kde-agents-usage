Free KDE Plasma 6 widget · Linux

Claude Code & Codex usage limits in your Plasma panel

Agents Usage is an open-source plasmoid that shows how much quota you have left in Claude Code, OpenAI Codex CLI, OpenCode and Ollama Cloud — and exactly when each limit resets. No more hitting the five-hour wall by surprise.

Know your AI coding quota before it runs out

AI coding agents enforce rolling usage limits — five-hour sessions, weekly caps, model-specific windows. Agents Usage puts every one of them on your Linux desktop, next to the clock.

Remaining quota per window

See the available percentage for each Claude Code window (five-hour, weekly, Sonnet, Opus) and each Codex rate limit at a glance.

Exact reset times

A live countdown plus the local reset day and time on a 24-hour clock, so you know when your Claude usage limit comes back.

Warning and critical levels

Set your own thresholds. The widget turns amber when quota runs low and red when it is critical.

Automatic refresh

Quota data refreshes on a configurable interval. Click refresh any time for an instant update.

Native Plasma 6 look

Built with QML and Kirigami. It follows your Breeze theme, accent color, fonts and light or dark mode, in a panel or on the desktop.

Private by design

No telemetry or analytics. The default setup reads only local files and never touches the network.

Install the widget on KDE Plasma 6

Requirements: KDE Plasma 6, Python 3.10 or newer and kpackagetool6. No extra Python packages.

Install from a release file

Download the latest .plasmoid from GitHub releases and install it:

kpackagetool6 --type Plasma/Applet --upgrade io.github.kde-agents-usage-@VERSION@.plasmoid

Or install from source

Clone the repository and run the installer. Run it again to update.

git clone https://github.com/serjor/kde-agents-usage.git
cd kde-agents-usage && ./install.sh

Add it to your panel

Right-click the panel, choose Add Widgets… and drag Agents Usage to a panel or the desktop. If it is not listed, restart Plasma:

systemctl --user restart plasma-plasmashell.service

Connect Claude Code

Add the offline collector to ~/.claude/settings.json:

{
  "statusLine": {
    "type": "command",
    "command": "python3 ~/.local/share/plasma/plasmoids/io.github.kde-agents-usage/contents/code/claude-statusline-collector"
  }
}

Codex works out of the box from local session files. Setup for the live Codex query, OpenCode and Ollama Cloud is in the full documentation.

Your prompts and tokens stay on your machine

Agents Usage reads only what it needs to show a number and a reset time. Every network source is opt-in and talks only to the official endpoint.

Read the security policy

  • No network requests in the default configuration
  • No telemetry, analytics or account identifiers collected
  • Never stores prompts, responses or source code
  • OAuth tokens and API keys kept in memory, never cached
  • Ollama key stored in KWallet or Secret Service
  • Cache files written with user-only permissions

Frequently asked questions

How can I see my Claude Code usage limit on Linux?

Install the Agents Usage widget on KDE Plasma 6 and connect its local status-line collector in ~/.claude/settings.json. The panel then shows the remaining percentage of your Claude Code five-hour and weekly windows, plus Sonnet and Opus windows when available.

When does my Claude Code five-hour limit reset?

Agents Usage shows a live countdown and the local reset day and time (24-hour clock) for every Claude Code quota window, so you know exactly when the five-hour and weekly limits reset.

Can I check OpenAI Codex CLI rate limits from the desktop?

Yes. By default the widget reads the last rate-limit event from local Codex session files. You can also enable a live query through the installed Codex CLI to see the current five-hour and weekly limits immediately.

Does Agents Usage send my data anywhere?

No. The default configuration makes no network requests and the project has no telemetry or analytics. Optional API sources are off by default and only contact the official Anthropic or Ollama endpoints.

Does it work with OpenCode and Ollama Cloud?

Yes. OpenCode quotas come from a small local provider export file, and Ollama Cloud usage comes from the ollama.com balance API with the API key stored in KWallet or another Secret Service provider.

Is Agents Usage free?

Yes. Agents Usage is free and open-source software under the MIT License, available on GitHub.
